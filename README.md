# ລາຍຈ່າຍນ້ອງ — แอปบันทึกค่าใช้จ่ายของน้องที่จีน

เว็บแอปขนาดเล็ก (ไฟล์เดียว ไม่ต้อง build) วางบน GitHub Pages และเก็บข้อมูลใน Supabase
หน้าแอปเป็นภาษาลาว สกุลเงินหยวน (¥)

**ทำอะไรได้บ้าง**
- บันทึกรายจ่ายประจำวัน: จำนวนเงิน หมวด รายละเอียด วันที่
- ติ๊ก "ต้องขอเงินคืนจากครอบครัว" แล้วแนบรูปใบเสร็จได้ (ระบบย่อรูปให้อัตโนมัติ)
- หน้าแรกโชว์ค่าเฉลี่ยต่อวัน (ไม่รวมรายการขอคืน) ยอดคาดการณ์ทั้งเดือน และสัดส่วนแยกตามหมวด
- หน้า "ขอเงินคืน" โชว์ยอดค้างคืน เลือกหลายรายการแล้วกด "คืนแล้ว" ได้ทีเดียว
- ปุ่มคัดลอกสรุปเป็นข้อความ เอาไปวางใน WhatsApp หรือ LINE ส่งพ่อแม่ได้
- น้องกับพี่ล็อกอินคนละบัญชี เห็นข้อมูลชุดเดียวกัน

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `config.js` | ใส่ URL และ anon key ของ Supabase (**แก้ไฟล์นี้ไฟล์เดียว**) |
| `supabase/schema.sql` | สร้างตาราง สิทธิ์การเข้าถึง และที่เก็บรูปใบเสร็จ |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | ใช้ตอนกด "Add to Home Screen" ให้เปิดเหมือนแอป |

## ขั้นตอนตั้งค่า (ใช้เวลาประมาณ 15 นาที)

### 1. Supabase: สร้างฐานข้อมูล
1. เข้า Supabase แล้วสร้าง Project ใหม่ (Region เลือก **Singapore** จะเร็วสุดสำหรับจีน/ลาว)
2. (ไม่ต้องใช้อีเมลจริง) ล็อกอินด้วยชื่อผู้ใช้ `nong` กับ `phi` — แอปแปลงเป็น `nong@nong-expense.app` / `phi@nong-expense.app` ให้เอง
3. ไปที่ **SQL Editor → New query** วางโค้ดทั้งไฟล์ลงไป แล้วกด **Run**

### 2. Supabase: สร้างบัญชีผู้ใช้ 2 คน
1. ไปที่ **Authentication → Users → Add user → Create new user**
2. ใส่อีเมล `nong@nong-expense.app` + รหัสผ่านของน้อง และติ๊ก **Auto Confirm User** ทำแบบเดียวกันอีกครั้งด้วย `phi@nong-expense.app` สำหรับพี่
   (ตอนล็อกอินในแอปพิมพ์แค่ `nong` หรือ `phi`)
3. ปิดการสมัครสมาชิกเอง เพื่อไม่ให้คนอื่นเข้ามาสมัคร: **Authentication → Sign In / Providers** → ปิด **Allow new users to sign up**
   (ถึงจะมีคนสมัครเข้ามาได้ ก็จะไม่เห็นข้อมูล เพราะ RLS อนุญาตเฉพาะอีเมลในตาราง `members`)

### 3. ใส่ค่า Supabase ลงในแอป
1. ไปที่ **Project Settings → API** (หรือ **Data API**) แล้วคัดลอก **Project URL** กับ **anon public key**
2. เปิดไฟล์ `config.js` แล้ววางค่าทั้งสองลงไป

> anon key เปิดเผยในเว็บได้ตามปกติ เพราะข้อมูลถูกป้องกันด้วย Row Level Security
> **ห้าม**เอา `service_role` key มาใส่เด็ดขาด

### 4. GitHub Pages: เอาขึ้นเว็บ
1. สร้าง repository ใหม่บน GitHub เช่น `faiy-expense` (เลือก Public หรือ Private ก็ได้ แต่ Private ต้องใช้แผน GitHub Pro ถึงจะเปิด Pages ได้)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (กด **Add file → Upload files** แล้วลากไฟล์ใส่)
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
4. รอประมาณ 1 นาที จะได้ลิงก์รูปแบบ `https://<ชื่อ-github>.github.io/Faiy-expense/`

### 5. ติดตั้งบนมือถือน้อง
- **iPhone**: เปิดลิงก์ใน Safari → ปุ่มแชร์ → **Add to Home Screen**
- **Android**: เปิดใน Chrome → เมนู ⋮ → **Add to Home screen / Install app**

## เรื่องที่ต้องรู้ตอนใช้งานในจีน
- GitHub Pages กับ Supabase **อาจช้าหรือเข้าไม่ได้ถ้าไม่เปิด VPN** ให้น้องเปิด VPN ตอนบันทึกข้อมูล
- ฟอนต์ลาวโหลดจาก jsDelivr ถ้าโหลดไม่ได้ แอปจะใช้ฟอนต์ลาวที่มีในเครื่องแทน (iPhone และ Android รุ่นใหม่มีอยู่แล้ว)
- ถ้าบันทึกไม่ผ่าน แอปจะแจ้งเตือนและ**เก็บข้อความในฟอร์มไว้** ให้เปิด VPN แล้วกดบันทึกใหม่ได้เลย

## ค่าเฉลี่ยต่อวันคำนวณอย่างไร
`ยอดรายจ่ายประจำวันของเดือน ÷ จำนวนวัน` โดยไม่รวมรายการขอคืน (เพราะครอบครัวจ่ายคืนแยกอยู่แล้ว)
จำนวนวัน = เฉพาะวันที่มีรายจ่ายประจำวันจริง (วันที่ไม่มีรายการไม่นับ)
"คาดว่าทั้งเดือน" = ค่าเฉลี่ยต่อวัน × จำนวนวันของเดือน ใช้เป็นตัวช่วยตัดสินใจว่าควรส่งเงินให้น้องเท่าไหร่

## ปรับแต่งเพิ่มเติม
- **เพิ่ม/แก้หมวด**: แก้ `CATS` ใน `index.html` และแก้ `check (category in (...))` ใน `schema.sql` ให้ตรงกัน
- **เพิ่มคนในครอบครัว** (เช่น พ่อแม่): เพิ่มแถวในตาราง `members` แล้วสร้าง user ใน Authentication ด้วยอีเมลเดียวกัน
